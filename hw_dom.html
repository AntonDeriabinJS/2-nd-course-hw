Задание 1

Скрытие и показ текста

Создайте кнопку, которая будет скрывать и показывать текст в заголовке <h1>. Нажатие на кнопку «Скрыть» скрывает текст заголовка. Повторное нажатие показывает текст снова. 

// Задание 1: Скрытие и показ текста
const heading = document.querySelector('#task1-heading');
const btn = document.querySelector('#task1-btn');

btn.addEventListener('click', () => {
    heading.style.display = heading.style.display === 'none'
        ? 'block'
        : 'none';
});

Это заголовок, который можно скрыть

Задание 4

Поиск и изменение элементов по классу

Найдите все элементы с классом description и измените их текст на «Измененный текст». 

// Задание 4: Поиск и изменение элементов по классу
const elements = document.querySelectorAll('.description');

for (let i = 0; i < elements.length; i++) {
    elements[i].textContent = 'Измененный текст';
}

Задание 6

Добавление нового элемента в DOM

Создайте кнопку, которая добавляет новый элемент <p> с текстом в конец документа. Нажатие на кнопку «Добавить элемент» добавляет в конец страницы новый абзац с текстом «Новый абзац». 

// Задание 6: Добавление нового элемента в DOM
const btn = document.querySelector('#task6-btn');
const container = document.querySelector('#task6-container');

btn.addEventListener('click', () => {
    const newP = document.createElement('p');
    newP.textContent = 'Новый абзац';
    newP.className = 'task-p';
    container.appendChild(newP);
});
Интерактивная демонстрация

Существующий абзац

Задание 7

Удаление элемента

Создайте кнопку, которая удаляет первый элемент <p> с классом description. Нажатие на кнопку «Удалить элемент» удаляет первый абзац с классом description со страницы. 

// Задание 7: Удаление элемента
const btn = document.querySelector('#task7-btn');

btn.addEventListener('click', () => {
    const firstDesc = document.querySelector('.task7-description');
    if (firstDesc) {
        firstDesc.remove();
    }
});
