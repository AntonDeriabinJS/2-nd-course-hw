Задание 1

Цикл до 10

Дан массив: [1, 5, 4, 10, 0, 3]. Создайте цикл, который выводит элементы до тех пор, пока не встретит значение 10. После вывода 10 цикл прекращает работу. 

// Задание 1: Цикл до 10
const arr1 = [1, 5, 4, 10, 0, 3];
for (let i = 0; i < arr1.length; i++) {
    if (arr1[i] === 10) {
        console.log(arr1[i]);
        break;
    }
    console.log(arr1[i]);
}

Задание 14

Чётные из случайных

Создайте массив из 10 случайных значений (0–10). Найдите все чётные и выведите оба массива. 

// Задание 14: Чётные из случайных
const randomArr = [];
for (let i = 0; i < 10; i++) {
    randomArr.push(Math.floor(Math.random() * 11));
}
const evenArr = randomArr.filter(n => n % 2 === 0);
console.log("Исходный:", randomArr);
console.log("Чётные:", evenArr);

Задание 15

Среднее арифметическое

Создайте массив из 6 случайных значений (1–10). Найдите среднее арифметическое. 

// Задание 15: Среднее арифметическое
const arr15 = [];
for (let i = 0; i < 6; i++) {
    arr15.push(Math.floor(Math.random() * 10) + 1);
}
const avg = arr15.reduce((sum, n) => sum + n, 0) / arr15.length;
console.log(arr15);
console.log("Среднее:", avg);
