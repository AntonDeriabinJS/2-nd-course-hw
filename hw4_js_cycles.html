Задание 4

Зарплаты сотрудников

Объект содержит имена сотрудников и их зарплаты. Пройдитесь по объекту с помощью цикла for-in и выведите информацию о каждом сотруднике. 

// Задание 4: Зарплаты сотрудников
let obj = {
    "Коля": '200',
    "Вася": '300',
    "Петя": '400'
};

for (let key in obj) {
    console.log(key + " — зарплата " + obj[key] + " долларов");
}

Задание 5

Деление числа на 2

Дано число n = 1000. Делите его на 2 до тех пор, пока результат не станет меньше 50. Определите полученное число и количество итераций. 

// Задание 5: Деление на 2
let n = 1000;
let num = 0;

while (n >= 50) {
    n = n / 2;
    num++;
}

console.log("Результат: " + n);
console.log("Количество итераций: " + num);

Задание 6

Напоминание о пятнице

Напишите программу, которая определяет все пятницы месяца (31 день) и выводит напоминание о подготовке отчёта. 

// Задание 6: Пятницы месяца
let firstFriday = 5; // Номер первой пятницы (от 1 до 7)

for (let day = firstFriday; day <= 31; day += 7) {
    console.log("Сегодня пятница, " + day + "-е число. Необходимо подготовить отчет.");
}
