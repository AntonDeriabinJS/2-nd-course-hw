Проверка пароля

Создайте переменную с паролем, запросите ввод у пользователя через prompt() и проверьте совпадение. 

// Задание 1: Проверка пароля
let password = 'пароль';
let userInput = prompt('Введите пароль');

if (userInput === password) {
    alert('Пароль введен верно');
} else {
    alert('Пароль введен неправильно');
}

Проверка на число больше 100 (логическое ИЛИ)

Если хотя бы одна из переменных d или e больше 100 — выводим «Верно». 

// Задание 3: Проверка с помощью ||

Задание 5

Определение сезона по номеру месяца

Напишите программу, которая по номеру месяца определяет сезон. Используйте оператор switch. 

// Задание 5: Определение сезона
let monthNumber = 12;

if (monthNumber > 13 || monthNumber < 1) {
    console.log('Некорректный номер месяца');
} else {
    switch (monthNumber) {
        case 12:
        case 1:
        case 2:
            console.log('зима');
            break;
        case 3:
        case 4:
        case 5:
            console.log('весна');
            break;
        case 6:
        case 7:
        case 8:
            console.log('лето');
            break;
        case 9:
        case 10:
        case 11:
            console.log('осень');
            break;
        default:
            console.log('Некорректный номер месяца');
    }
}
